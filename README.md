# InAmigos Foundation - NGO Awareness Website

## About the Project

The InAmigos Foundation NGO Awareness Website is a frontend web development project created to spread awareness about social activities, encourage community participation, and motivate people to contribute towards society.

The website provides information about the foundation, its social initiatives, community impact, and volunteering opportunities.

## Objectives

- Spread awareness about social work and community development.
- Provide information about the foundation and its activities.
- Showcase different social initiatives and projects.
- Encourage people to become volunteers.
- Create a platform to share social work experiences.

## Features

- **Home Page:** Introduction to the InAmigos Foundation.
- **About Us:** Information about the foundation and its activities.
- **Projects:** Details about different social initiatives.
- **Our Impact:** Highlights the foundation's social contributions.
- **Community:** A platform to showcase social work activities.
- **Become a Volunteer:** A registration form for people interested in volunteering.
- **Responsive Design:** Website layout adapts to different screen sizes.
- **Navigation Bar:** Easy navigation between different website pages.

## Projects Covered

1. SEVA
2. BACHPANSHALA
